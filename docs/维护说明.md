# 系统维护说明

## 版本信息
- 日期：2024-XX-XX
- 维护范围：数据读取、统计计算、可视化绘图、界面显示

## 排查结论
1. **计算统计**：原有 `DataManager.get_cohort_statistics` 对缺失列和非数值内容缺少容错，导致实际数据集可能抛出异常或生成 `NaN`。
2. **数据兜底**：`load_real_data_schema_less` 未统一转换 `action/reward/terminal/timestep` 字段类型，也未对缺失动作做兜底，读取开放数据时容易报错或显示异常。
3. **绘图/显示**：校准曲线绘图函数假设传入 DataFrame 含 `ece` 列，实际 `evaluate_calibration` 未写入该信息，导致绘图阶段访问异常；同时空数据集时无提示。

## 变更摘要
- **数据读取增强**：
  - 自动补全缺失的 `action`、`reward`、`terminal` 字段并转换为数值类型。
  - 统一 `timestep`、特征列的数值化，避免混入字符串导致后续计算失败。
  - 加强 `get_cohort_statistics` 的健壮性，缺列时返回合理默认值并忽略非数值内容。
- **可视化修复**：
  - `evaluate_calibration` 现在返回包含 `ece/mce` 的 DataFrame，即使数据为空也能安全运行。
  - `plot_calibration_curve` 支持直接接收评估结果字典或 DataFrame，对空数据集给出提示文本并在缺少 `ece` 时跳过显示。

## 使用建议
- 在接入真实数据前，优先调用 `load_real_data_schema_less` 完成列名兜底，再执行统计或绘图。
- 绘图函数接受评估字典，可直接传入 `evaluate_calibration` 的返回值，减少中间状态转换。
- 对外展示前建议结合 `get_cohort_statistics` 的返回值校验数据完整性。
- 上传真实数据时遵循界面中的“上传检查清单”，确保包含患者标识、时间步、动作、奖励及 episode 终止信息，以避免轨迹重建失败。
